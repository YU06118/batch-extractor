# 批量解压控制台 · 程序文档

> 本文档对应仓库当前最新代码版本（2026-11-16），与源码同步维护。
> 面向使用与二次开发：安装配置与操作方法见 [使用文档](./使用文档.md)，早期设计决策与工程实践记录见 [架构与工程知识](./架构与工程知识.md)。

## 1. 项目概述

「批量解压控制台」是一个**零第三方依赖**的批量解压工具，围绕同一个核心引擎 `batch_extract.py` 提供三种运行形态：

| 形态 | 入口 | 适用场景 |
| --- | --- | --- |
| **桌面窗口（推荐）** | `batch_gui.py`（可打包为双击 exe） | 日常使用，无需浏览器、无需命令行 |
| **Web 页面** | `start.bat` / `launch.py` / `python batch_extract.py --serve` | 喜欢浏览器操作页面、或需要远程访问本机 |
| **命令行 CLI** | `python batch_extract.py --input-dir ... --output ...` | 脚本集成、定时任务、管道处理 |

核心能力：

- 递归扫描目录或手动指定文件列表，批量解压
- 格式自动识别：扩展名优先，文件头魔数兜底（无扩展名文件也能识别）
- 分卷自动归组：`7z.001~005`、`xxx.7z.001`、`xxx.part1.rar` 整组算 1 个包，缺卷明确报 `missing_volume`
- 加密包密码策略：单密码 / 候选密码列表 / 密码本文件，明文只存在于任务内存
- 统一汇总输出（schema `batch-extract-summary/v1`）：成功/失败/跳过三类文件条目按原因码分组，分卷组明细、密码统计（只给数量）
- 安全落盘：包内路径越界拦截（绝对路径 / `..` / 盘符 / 符号链接 / Windows 保留名），先解压到临时暂存区再整体落地，默认同名跳过（conflict）

## 2. 总体架构

```
┌─────────────────────────────────────────────────────┐
│                  使用界面层（三选一）                   │
│                                                     │
│  batch_gui.py          web/index.html      CLI 参数  │
│  (tkinter 桌面窗口)     (浏览器页面)         (argparse)│
│       │                     │                  │     │
│       │ 直接函数调用          │ HTTP API         │     │
│       │ run_extract(cfg,    │ POST /api/jobs   │     │
│       │  emit回调)          │ GET  /api/jobs/N │     │
│       │                     │ GET  /api/meta   │     │
│  entry_gui.py ──┐    batch_extract.serve()        │
│  (exe双击入口,    │    (ThreadingHTTPServer)        │
│   Web形态专用)   ─┘                                  │
├─────────────────────────────────────────────────────┤
│                  核心引擎层 batch_extract.py          │
│                                                     │
│  collect_archives()  收集与归组                       │
│    ├─ detect_format()      格式识别（扩展名+魔数）      │
│    ├─ parse_volume()       分卷识别                   │
│    └─ scan_volume_group()  分卷组连续性检查            │
│  run_extract(cfg, emit)  主流水线（恒返回汇总，不抛异常）│
│    ├─ PasswordContext      密码上下文（内存、可擦除）    │
│    ├─ stage_archive()      解压到临时暂存区            │
│    │   ├─ _stage_zip       zipfile（含传统加密/AES探测）│
│    │   ├─ _stage_tar       tarfile（gz/bz2/xz 透明解） │
│    │   ├─ _stage_single    单文件流解压                │
│    │   └─ _stage_external  调用 7-Zip（subprocess）    │
│    ├─ safe_relpath()       包内路径安全化（越界拦截）    │
│    └─ relocate()           暂存区 → 输出目录落地        │
│                             （覆盖/冲突跳过策略）       │
├─────────────────────────────────────────────────────┤
│                  支撑与工具层                          │
│  selftest.py        99 项确定性自测断言                │
│  make_package.py    生成分发 zip + MANIFEST（SHA256）  │
│  launch.py/start.bat  Web 形态启动器（Python 定位、    │
│                     端口探测、状态查询、安全停止）        │
│  PyInstaller        打包桌面版 / Web版 exe（可选）      │
└─────────────────────────────────────────────────────┘
```

三种形态共享同一引擎与同一汇总结构，界面层只做输入采集与结果呈现，不含业务逻辑。

## 3. 模块划分

### 3.1 batch_extract.py（核心引擎 + CLI + HTTP 服务，约 1500 行）

标准库零第三方依赖（`zipfile` / `tarfile` / `subprocess` / `http.server` 等）。

| 区块 | 关键符号 | 职责 |
| --- | --- | --- |
| 常量与约定 | `SCHEMA` `REASONS` `EXT_MAP` `TAR_EXT` `SINGLE_EXT` `EXTERNAL_EXT` `NUM_VOLUME_RE` `PART_VOLUME_RE` | 汇总 schema 版本号、原因码→中文说明表、扩展名→处理器族映射、分卷命名正则 |
| 异常 | `UnsafePath` `ArchiveError(reason, detail)` | 路径越界 / 外部工具整包失败，均带原因码 |
| 密码 | `PasswordContext` `_pwd_bytes` | 汇集密码/候选密码/密码本；`scrub()` 从任何输出文本中擦除明文；`auth()` 只返回数量（provided / candidates / attempted / solved） |
| 格式识别 | `detect_format(path)` | 扩展名优先（多段后缀 `.tar.gz` 先匹配），读前 512 字节魔数兜底；分卷一律归 external 族 |
| 7-Zip 探测 | `find_external_tool()` `_registry_7z_candidates()` | PATH → 注册表 InstallLocation（双视图）→ 常见目录，找到即自动启用 |
| 路径安全 | `safe_relpath()` `zip_entry_name()` `tar_entry_name()` `WIN_RESERVED` | 拦截绝对路径、`..`、盘符、符号链接、非法字符、Windows 保留名（CON/NUL/COM1…）；顺带处理编码 |
| 归组 | `parse_volume()` `scan_volume_group()` `collect_archives(cfg)` | 同目录 + 同组名 + 同命名风格 = 一组；编号连续性检查，缺卷整组报 `missing_volume` |
| 解压 | `stage_archive()` → `_stage_zip` `_stage_tar` `_stage_single` `_stage_external` | 全部先写入 `tempfile.TemporaryDirectory` 暂存区；zip 传统加密用 Python 内置解密，AES 加密 zip 交 7-Zip |
| 落地 | `relocate(staging, dest_root, …)` | 按「按包名建子目录 / 平铺」输出；同名默认跳过（conflict），可选覆盖；暂存半成品不落地 |
| 主流水线 | `run_extract(cfg, emit) -> summary` | 配置校验 → 收集归组 → 逐包解压落地 → 统一汇总；**不向外抛业务异常**，所有失败都进汇总 |
| HTTP 服务 | `Handler` `serve(host, port)` | `GET /` 页面；`GET /api/meta` 能力与格式说明；`POST /api/jobs` 提交任务（202）；`GET /api/jobs/<id>` 轮询进度与汇总 |
| CLI | `main(argv)` | 参数与 API 字段一一对应；stdout 恒为汇总 JSON，日志走 stderr |

### 3.2 batch_gui.py（桌面窗口，约 400 行）

- tkinter + ttk 实现的标准桌面窗口，三组卡片式布局：选择压缩包 / 输出与选项 / 运行日志
- 解压在后台线程执行，通过 `queue.Queue` + `after()` 轮询把引擎 `emit` 日志流式刷到界面，主线程永不阻塞
- 完成后展示文件条目与压缩包两级统计、失败/跳过分组明细；支持一键打开输出目录、复制汇总 JSON
- 环境变量 `BX_GUI_SMOKE=1`：启动 2 秒后自动退出，供自动化冒烟验证

### 3.3 entry_gui.py（Web 形态 exe 双击入口）

- 端口复用探测（8765 起 20 个端口，`/api/meta` 校验是否本服务）→ 启动服务 → 打开系统浏览器 → 常驻
- `BX_NO_BROWSER=1` 供自动化验证

### 3.4 web/index.html（Web 页面，单文件零外部资源）

- 白底 + 蓝主色的简洁设计（参考 Bandizip），系统字体，无任何 CDN / 字体外链，完全离线可用
- 与引擎的契约：`POST /api/jobs` 提交，`GET /api/jobs/<id>` 轮询，渲染汇总的 counts / groups / volumeSets / auth

### 3.5 selftest.py（确定性自测）

- 99 项断言：引擎单测（分卷归组、路径安全、密码上下文、格式识别）+ 真实样例解压 + HTTP 端到端 + 前端静态 QA + WCAG 对比度实算
- 全部通过时输出 `SELFTEST_ALL_PASS`

### 3.6 launch.py / start.bat（Web 形态启动器）与 make_package.py（分发打包）

- `start.bat`（GBK 编码）：定位 Python → 调 `launch.py` 起服务开浏览器；顶部可编辑端口 / 浏览器路径
- `launch.py`：`--status` 查询、`--stop` 安全停止、`--port` 换端口、`--browser` 指定浏览器
- `make_package.py`：生成完整分发 zip，自动生成含 SHA256 的 `MANIFEST.txt`

## 4. 核心逻辑

### 4.1 run_extract 主流水线

```
cfg 输入 ──► 配置校验（输出目录/mode/密码合法性，问题也进汇总不抛异常）
        ──► collect_archives（目录递归或文件列表 → 格式识别 → 分卷归组）
        ──► 逐包循环：
              ├─ 整组失败（缺卷等）→ 记 1 条包级失败，继续下一组
              ├─ stage_archive 解压到临时暂存区（zip/tar/single/external 四族）
              │    条目级失败实时记录（corrupt / password_required / wrong_password…）
              ├─ relocate 暂存区 → 输出目录（覆盖 或 conflict 跳过）
              └─ 包级计数 ok / partial / failed
        ──► 统一汇总（schema batch-extract-summary/v1）
```

设计要点：

- **暂存区策略**：先解到临时目录再整体落地，解压中途失败（如外部工具整体报错）不会留下半成品污染输出目录
- **不抛异常原则**：`run_extract` 对配置错误、单包失败、未预期异常全部兜底进汇总，保证一批任务处理到底
- **emit 回调**：日志实时回调给界面层（GUI 队列 / HTTP messages / CLI stderr），同一份数据三种呈现

### 4.2 分卷归组

- 数字卷正则 `xxx.001~9999`（含 `xxx.7z.001`）与 RAR 卷 `xxx.partN.rar`
- 同目录 + 同组名（去编号后前缀）+ 同命名风格 = 一组；只解首卷，7-Zip 自动串读后续卷
- 编号断档 → 整组 `missing_volume`，不解压不落地；组内多卷时在汇总 `volumeSets` 给出首卷/末卷/缺失编号

### 4.3 密码策略

| 来源 | 字段 | 说明 |
| --- | --- | --- |
| 界面/CLI 单密码 | `password` | 优先使用 |
| 候选密码列表 | `passwords` | 批次内不同包密码不同时全部列出，逐个尝试 |
| 密码本文件 | `passwordFile` | UTF-8 一行一个；CLI 亦可用环境变量 `BX_PASSWORD` / `BX_PASSWORD_FILE` |

- 缺密码 → `password_required`；全部候选尝试失败 → `wrong_password`，该包跳过不落地
- **明文只在任务内存**：不写入 messages / items / 汇总 / 日志 / 本地存储；`PasswordContext.scrub()` 对任何可能外发的文本先擦除明文；汇总 `auth` 只返回数量

### 4.4 安全设计

- 包内路径越界（绝对路径 / `..` / 盘符 / 符号链接 / 非法字符 / Windows 保留设备名）→ `unsafe_path` 拦截，条目不落地
- 输出冲突默认跳过（`conflict`），需要覆盖必须显式勾选/传参
- Web 服务仅监听 `127.0.0.1`，不对局域网开放

### 4.5 统一汇总 schema（batch-extract-summary/v1）

```jsonc
{
  "schema": "batch-extract-summary/v1",
  "counts":       {"success": 0, "failed": 0, "skipped": 0},   // 文件条目级
  "archiveCounts": {"ok": 0, "partial": 0, "failed": 0},      // 压缩包级
  "groups": {
    "failed":  [{"reason": "...", "label": "中文说明", "count": 0, "items": [{"archive","path","detail"}]}],
    "skipped": [ ... 同结构 ... ]
  },
  "items":     [{"status","archive","path","reason","detail"}], // 全量明细
  "messages":  [{"level","text","at"}],                        // 运行日志（上限 5000 条）
  "volumeSets": [{"name","count","missing":[],"first","last"}],
  "auth":      {"provided": true, "candidates": 2, "attempted": 1, "solved": 1},
  "outputDir": "…", "startedAt": "…", "finishedAt": "…"
}
```

### 4.6 原因码一览（REASONS）

| 原因码 | 含义 |
| --- | --- |
| `corrupt` | 数据损坏 / CRC 失败 / 截断 |
| `password_required` | 已加密但未提供密码 |
| `wrong_password` | 全部候选密码均不正确 |
| `missing_volume` | 分卷编号不连续（缺首卷或中间卷） |
| `unsupported` | 格式不支持，或缺少 7-Zip（.7z/.rar/分卷） |
| `unsafe_path` | 包内路径越界 |
| `conflict` | 目标已存在且未勾选覆盖 |
| `io_error` | 读写失败（权限 / 磁盘 / 路径过长） |
| `invalid_input` | 输入配置有问题 |
| `external_failed` | 外部工具执行失败 |
| `empty` | 压缩包内没有文件条目 |
| `encrypted` / `encrypted_generic` | 加密兜底原因码（保留兼容） |

## 5. 依赖说明

| 依赖 | 必需性 | 说明 |
| --- | --- | --- |
| Python 标准库 | 必需（源码运行） | zipfile / tarfile / subprocess / http.server / tkinter 等，全部随 Python 自带 |
| Python 3.8+ | 源码运行必需 | 桌面窗口形态需带 tkinter 的 Python（Windows 官方安装包默认含 tkinter） |
| 7-Zip（7z.exe） | 可选 | 启用 `.7z / .rar / 数字分卷 / RAR 分卷 / AES 加密 ZIP`；未装时这些格式明确报 `unsupported`，内置格式不受影响。装好后无需任何配置，自动探测（PATH → 注册表 → 常见目录） |
| PyInstaller ≥ 6.x | 仅打包 exe 时需要 | `pip install pyinstaller` |
| 浏览器 | 仅 Web 形态需要 | 页面零外部资源，离线可用 |

## 6. 打包为 exe

```powershell
# 桌面窗口版（推荐，双击直接弹窗）
pip install pyinstaller
pyinstaller --onefile --noconsole --name "批量解压控制台" batch_gui.py
# 产物：dist/批量解压控制台.exe（约 14 MB，免安装）

# Web 版（双击后起本地服务并打开浏览器页面）
pyinstaller --onefile --noconsole --add-data "web;web" entry_gui.py
```

说明：

- 打包需使用**带 tkinter 的 Python**（精简版/嵌入式 Python 缺 tkinter 会构建出不可用产物）
- 桌面版默认输出目录自动指向 exe 所在目录下的 `output`；重复双击不会重复起服务
- 分发归档（含全部源码 + 样例 + MANIFEST 校验清单）可运行 `python make_package.py` 一键生成
