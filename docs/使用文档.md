# 批量解压控制台 · 使用文档

> 本文档对应仓库当前最新代码版本（2026-11-16）。
> 架构、模块与依赖的技术细节见 [程序文档](./程序文档.md)。

## 1. 程序简介

批量解压控制台用于把一个目录（含子目录）里散落的压缩包一次性全部解压：自动识别格式、自动归组分卷、自动尝试密码，结束后给出「成功 / 失败 / 跳过」的明细汇总，而不是逐个手动右键解压。

三种使用方式，选一种即可：

| 方式 | 适合谁 | 怎么启动 |
| --- | --- | --- |
| **桌面窗口 exe（推荐）** | 日常使用 | 双击 `批量解压控制台.exe` 直接弹窗 |
| 源码桌面窗口 | 装有 Python 的用户 | `python batch_gui.py` |
| Web 页面 | 喜欢浏览器页面 | 双击 `start.bat`，浏览器自动打开页面 |
| 命令行 | 脚本 / 定时任务 | `python batch_extract.py --input-dir … --output …` |

## 2. 获取与安装

### 2.1 方式一：直接使用 exe（无需安装 Python）

1. 获取 `批量解压控制台.exe`（单文件、约 14 MB、免安装）
2. 放到任意目录（建议单独建一个工作目录），双击运行
3. 首次运行若被 Windows SmartScreen 拦截：点「更多信息 → 仍要运行」

默认输出目录自动定为 exe 所在目录下的 `output` 文件夹；重复双击会直接复用已运行的实例，不会重复启动。

### 2.2 方式二：源码运行（Python 3.8+）

```bash
# 1. 获取仓库源码（git clone 或下载 zip 解压）
# 2. 直接运行桌面窗口
python batch_gui.py

# 或运行 Web 页面
start.bat          # Windows，双击即可
python launch.py   # 等价命令

# 或命令行形态（见第 5 节）
python batch_extract.py --help
```

依赖说明：全部功能只依赖 Python 标准库，无需 `pip install` 任何第三方包；桌面窗口需要 Python 自带 tkinter（Windows 官方安装包默认含）。

### 2.3 可选安装：7-Zip（解锁 .7z / .rar / 分卷 / AES 加密 ZIP）

- 安装 [7-Zip](https://www.7-zip.org/)（默认路径即可，装到 D 盘等自定义位置也能通过注册表自动探测）
- 装好后**无需任何配置**，程序自动启用；桌面窗口底部状态栏会显示「外部工具：7-Zip 已就绪」
- 未安装 7-Zip 时：zip / tar.gz / gz / bz2 / xz 等内置格式不受影响；`.7z / .rar / .001 分卷` 会明确标记为「不支持」而不是静默失败

## 3. 配置说明（桌面窗口）

### 3.1 选择压缩包

| 配置项 | 说明 |
| --- | --- |
| 扫描整个文件夹 | 递归扫描所选目录及全部子目录，自动找出压缩包并归组分卷（推荐） |
| 手动选择压缩包文件 | 精确控制要处理哪些文件；「添加…」可多选，「移除选中 / 清空」管理列表 |

### 3.2 输出与选项

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| 输出目录 | exe/脚本所在目录下的 `output` | 所有解压结果落到这里；不存在会自动创建 |
| 覆盖已存在的文件 | 不勾选 | 默认遇到同名文件跳过（原因码 `conflict`）；勾选后用新文件覆盖 |
| 按压缩包名建立子文件夹 | 勾选 | `demo.zip` 解到 `输出目录\demo\`；不勾选则所有文件平铺到输出目录 |

### 3.3 密码（处理加密包时填写）

| 配置项 | 说明 |
| --- | --- |
| 解压密码 | 所有包统一用这一个密码 |
| 候选密码 | 逗号分隔多个密码；批次内不同包密码不同时全部列上，程序对每个加密包逐个尝试 |
| 密码本文件 | UTF-8 文本、一行一个密码，适合密码较多的场景 |

密码安全：明文只在本机内存中用于本次解压，**不写入日志、不写入汇总 JSON、不做本地存储**；汇总里只有数量统计。

## 4. 常用操作示例

### 4.1 批量解压整个目录（最常用）

1. 选「扫描整个文件夹」，浏览选择如 `D:\下载\压缩包合集`
2. 确认输出目录（默认即可）
3. 点「开始解压」
4. 日志区实时滚动显示进度 `[1/23] xxx.zip …`；结束后弹窗提示结果
5. 点「打开输出目录」查看解压结果；点「复制汇总」可把完整 JSON 报告粘到别处存档

### 4.2 处理加密压缩包

1. 密码区填入密码；不同包密码不同就填候选密码：`pass1, pass2, pass3`
2. 开始解压。缺密码的包标记 `password_required`，密码全不对的标记 `wrong_password`，均不影响其他包继续处理
3. 日志与汇总里按包明确列出哪些密码问题，补对密码后勾选「覆盖已存在的文件」重跑即可

### 4.3 处理分卷压缩包（如 7z.001~005）

1. 直接「扫描整个文件夹」即可，无需手动选
2. 同目录同名分卷自动算一组（只显示 7z.001 一个包）；缺中间卷会整组报 `missing_volume` 并提示缺哪些编号
3. 需要 7-Zip 已安装

### 4.4 只解压指定的几个文件

1. 选「手动选择压缩包文件」→「添加…」多选目标文件（分卷只需选首卷或全部卷，会自动去重）
2. 其余步骤同 4.1

### 4.5 命令行批量解压（脚本/定时任务）

```bash
# 目录扫描
python batch_extract.py --input-dir "D:\下载\合集" --output "D:\解压结果"

# 指定文件（分卷只需填首卷）
python batch_extract.py --archives "D:\a.7z.001" "D:\b.zip" --output "D:\out"

# 密码与覆盖
python batch_extract.py --input-dir "D:\合集" --output "D:\out" --password demo123 --overwrite

# 候选密码（可重复 --password）与密码本
python batch_extract.py --input-dir "D:\合集" --output "D:\out" --password p1 --password p2
python batch_extract.py --input-dir "D:\合集" --output "D:\out" --password-file pwd.txt

# 不按包名建子目录
python batch_extract.py --input-dir "D:\合集" --output "D:\out" --no-archive-subdir
```

stdout 恒为汇总 JSON（脚本可解析），日志走 stderr。

### 4.6 Web 页面形态

```bash
start.bat                  # 双击：起服务 + 打开浏览器页面
python launch.py --status  # 查看服务状态
python launch.py --stop    # 安全停止服务
python launch.py --port 8877
```

## 5. 汇总结果怎么看

| 项目 | 含义 |
| --- | --- |
| 成功 / 失败 / 跳过 | 文件条目级统计 |
| 成功 / 部分成功 / 失败 | 压缩包级统计（部分成功 = 包内部分文件失败） |
| 失败（原因码分组） | 见下表，每项附压缩包名与具体原因 |
| 复制汇总 | 完整 JSON（含全部明细），便于存档或反馈问题 |

常见原因码速查：

| 原因码 | 含义与处理 |
| --- | --- |
| `conflict` | 输出目录已有同名文件 → 确认后勾选「覆盖」重跑 |
| `wrong_password` | 密码不对 → 核对候选密码后重跑 |
| `password_required` | 未提供密码 → 填密码重跑 |
| `corrupt` | 包或条目损坏（截断/CRC 失败）→ 重新获取该压缩包 |
| `missing_volume` | 分卷缺卷 → 补齐缺失编号的卷 |
| `unsupported` | 格式不支持或缺 7-Zip → 安装 7-Zip 后重跑 |
| `unsafe_path` | 包内路径越界（绝对路径/`..`/保留名）→ 程序主动拦截，属预期保护 |
| `io_error` | 权限/磁盘/路径过长 → 检查输出盘与只读属性 |

## 6. 常见问题（FAQ）

**Q1：双击 exe 没有反应？**
先检查是否被 Windows SmartScreen 或杀毒软件拦截（任务栏/通知中心有提示，选「仍要运行/允许」）。若仍有问题，可下载仓库源码用 `python batch_gui.py` 运行，并把报错信息反馈。

**Q2：.7z / .rar / .001 文件提示「不支持」？**
本机未装 7-Zip。安装后**无需重启程序**即自动探测启用（状态栏会变为「7-Zip 已就绪」）。zip / tar.gz / gz / bz2 / xz 等格式不装也能解。

**Q3：重复运行时大部分文件被「跳过（conflict）」？**
默认策略是同名不覆盖，防止误删已有结果。确认要覆盖时勾选「覆盖已存在的文件」再跑。

**Q4：密码明明填了还是 wrong_password？**
程序会尝试你提供的全部候选密码；zip 老式加密与 AES 加密都支持（AES 需 7-Zip）。注意候选密码区分大小写、不要带多余空格。

**Q5：解压中文文件名的 zip 出现乱码？**
引擎对常见中文编码（GBK/CP437 等）做了自动探测与修复；若个别老归档仍乱码，解出的文件名可从汇总 JSON 中核对原始条目名。

**Q6：端口 8765 被占用（Web 形态）？**
`python launch.py --port 8877` 换端口，或编辑 start.bat 顶部的 `PORT`；桌面窗口形态不使用网络端口，无此问题。

**Q7：解压到一半出错了，输出目录会有半成品吗？**
不会。所有文件先解到系统临时暂存区，整包成功后才落盘；失败包的半成品自动清理，不会污染输出目录。

**Q8：怎么把程序分发给同事？**
两种方式：① 直接发 exe 单文件；② 运行 `python make_package.py` 生成完整分发 zip（含源码、样例、SHA256 校验清单 MANIFEST.txt）。

**Q9：想确认程序逻辑没被改动/完整无损？**
`python selftest.py` 跑 99 项确定性自测，全部通过时输出 `SELFTEST_ALL_PASS`；分发包可用 MANIFEST.txt 里的 SHA256 逐文件核对。
